# 既存動画の手指解析 (v0.4 / 2026-10-06)

公開URLは https://daijirohaba.github.io/mediapipe-hand-motion/ のままです。各画面上部の「既存動画の解析」から専用画面を開きます。Chrome/EdgeでMP4/WebMを推奨。MOV/AVI/M4Vは内部コーデックによって復号できない場合があります。動画をアップロードせず、音声を再生・解析せず、カメラ許可も要求しません。

## 入力と3D

- 単眼: 動画Aを指定。2Dとモデル相対3Dを表示・保存。従来の単眼画面の「動画ファイル」も利用可能です。
- 複数動画: A/B/Cに1〜3本を指定。各映像のランドマークと座標・Summaryを1つのZIPに保存。別の動作の動画は幾何3Dに統合できません。
- 校正3D: Aだけなら単眼のモデル相対3D。実寸の共通座標には、同じ動作を同時撮影した2〜3本と撮影時の校正JSONが必要。単眼worldLandmarksは平均しません。

## 操作

1. 動画A/B/Cを校正JSONの同じIDに割り当てます。動画から元カメラのdeviceHashを検証できないため、撮影記録で対応を確認してください。
2. 同じイベント（光など）を確認します。「開始オフセット」は共通時刻0秒に対応する元動画の秒数。Aの0秒とBの2秒を合わせるならA=0、B=2。負の値も可。全動画の共通時間区間のみ解析します。
3. 複数視点を幾何統合する場合は校正JSONと確認チェックを指定。機器・配置・焦点・ズームが同一である必要があります。解像度不一致はエラー。反転・クロップ・回転・拡大済み動画には元の校正を流用しないでください。
4. sample fpsを指定し開始。長時間は0.5〜1 fps、短い動作は5〜10 fpsなどを選択。最大3,000組。停止・タブ非表示で中止し、解析済み結果はページを閉じる前に保存できます。

復号フレームmediaTimeからオフセットを引いて対応時刻を求めます。復号時刻が不明、時刻差が上限超過、片手が2視点以上で検出できない、再投影等のQC不合格の場合は統合を保留します。オフセットだけで露光同期は保証できず、長時間の時計ドリフトも自動補正しません。

## ZIP

- `coordinates/A/`, `B/`, `C/`: 各動画2D CSVとモデル相対3D CSV。日本語・UTF-8 BOM付き。
- `coordinates/fused_3d.csv`: 複数動画と校正による幾何推定。不採用点は空欄と理由を保存。
- `reports/*_summary.json`: 元ファイル名・サイズ・動画長・オフセット・解析数・検出数。
- `reports/summary_all.json`, `manifest.json`, `timing_qc.json`, `README_RESULTS_ja.txt`: 全体結果、時刻対応、同期/カメラ対応未検証、停止/エラー/上限。
- `calibrations/*.json`: 使用した校正JSON。

単眼のmm換算はモデル相対値です。校正3Dも接触面・押し込み量ではありません。新たな録画・動画のZIPへの複製は行いません。画面の骨格描画と数値結果を確認してください。
